# Аналитика Ozon + МойСклад

Локальное приложение на Streamlit для сопоставления продаж Ozon с себестоимостью из МоегоСклада.

## Запуск

```bash
pip install -r requirements.txt
streamlit run ozon_moysklad_analytics.py
```

## Доступы

- Ozon: `Client-Id` и `Api-Key` из кабинета продавца.
- МойСклад: Bearer-токен JSON API.

Ключи вводятся в боковой панели и не записываются приложением в файл. Не публикуйте скриншоты с ключами.

## Расчёты

- Продажи и заказанные единицы берутся из Ozon Seller API `/v1/analytics/data`.
- SKU сопоставляется с `offer_id` через `/v3/product/info/list`.
- `offer_id` связывается с кодом МоегоСклада.
- Себестоимость и остаток загружаются из `/report/stock/all`.
- Баллы Ozon за скидки берутся из `posting.products[].commission.bonus` в начислениях и привязываются к SKU.
- Прибыль до расходов Ozon = выручка + баллы Ozon − себестоимость × заказанные единицы.
- Финансовые начисления загружаются по каждому дню через `/v1/finance/accrual/by-day` с постраничным курсором `last_id`. Отрицательные суммы показываются как расходы; общая оценка после расходов вычитает их, но не распределяет по SKU.

## Ограничения

- Если Ozon сообщает о следующей странице аналитики, приложение предупреждает, что результат содержит только первые 1 000 строк. Это помогает не скрывать неполные данные и не делать дополнительные запросы к ограниченному методу.
- Если финансовые операции недоступны, отчёт по товарам всё равно формируется, а оценка после расходов не показывается.
- Товары без совпавшего кода отмечаются отдельно. Их прибыль не следует считать подтверждённой.
- Используются заказанные, а не фактически доставленные единицы. Возвраты и корректировки могут менять фактический финансовый результат.
- Финансовые операции не распределены по товарам; итоговая оценка сверяется с отчётами Ozon.
- Период отчёта ограничен одним годом.

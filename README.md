# Аналитика юнит-экономики Ozon + МойСклад

Streamlit-приложение принимает XLSX-выгрузку «Юнит-экономика» из Ozon, добавляет историческую себестоимость из МоегоСклада и пересчитывает прибыль по товарам.

## Запуск

```bash
pip install -r requirements.txt
streamlit run ozon_moysklad_analytics.py
```

## Подключение

Нужен Bearer-токен JSON API МоегоСклада. В Streamlit Community Cloud добавьте в **App settings → Secrets**:

```toml
MOYSKLAD_TOKEN = "ваш токен МоегоСклада"
```

Можно временно ввести токен в боковой панели. Доступы Ozon API приложению не требуются: источником данных служит загруженный файл.

## Файл и расчёты

- Загрузите XLSX-выгрузку юнит-экономики Ozon. Приложение читает SKU, артикул, название, цену, выручку, баллы, программы партнёров, комиссии, услуги, количества и показатели прибыли из таблицы.
- Артикул из файла сопоставляется с кодом товара в МоемСкладе.
- Себестоимость загружается из проведённых документов «Приёмка» (`/entity/supply`) и «Оприходование» (`/entity/enter`) как средневзвешенная цена поступления: `сумма (цена позиции × количество) / сумма количества`. Цены в API указаны в копейках. Остатки не загружаются.
- Прибыль за единицу пересчитывается заменой себестоимости: `«Прибыль за шт» из Ozon + себестоимость Ozon из файла − себестоимость из МоегоСклада`. Маржинальность товара: `прибыль за единицу / текущая цена × 100%`. Прибыль за период: `прибыль за единицу × (доставлено − возвращено)`; сводная маржинальность взвешивается по текущей цене и этому количеству.
- Если для товара нет себестоимости в МоёмСкладе, итоговая прибыль по нему не рассчитывается и строка помечается.
- История себестоимости кэшируется на 24 часа. Кнопка «Обновить себестоимость» очищает кэш и заново загружает историю.
- На вкладке «Целевая маржинальность» можно задать целевой процент. Расчёт использует текущую цену из файла и пересчитанную прибыль за единицу: `(целевая доля × цена − прибыль за единицу) / (1 − целевая доля)`. Надбавка не опускается ниже нуля.
- На вкладке «Калькулятор нового товара» комиссия и эквайринг усредняются как доля от `текущая цена × (доставлено − возвращено)`, а прочие расходы — как средняя сумма на проданную единицу. Цена: `(себестоимость + прочие расходы на единицу) / (1 − доля комиссии и эквайринга − целевая маржинальность)`.
- Полный обогащённый отчёт и расчёт рекомендуемых цен можно скачать в CSV.

# Массовый калькулятор юнит-экономики Ozon

Отдельное Streamlit-приложение для загрузки данных из Seller API Ozon и JSON API МоегоСклада.

## Что загружает

- Ozon: список активных и скрытых товаров, цену продавца, минимальную цену, старую цену, цену для покупателя, объёмный вес и габариты упаковки.
- МойСклад: последние пять проведённых документов «Приёмка» для каждого кода товара. Себестоимость считается как взвешенная средняя цена строк этих пяти документов: сумма стоимости / сумма количества. Код товара сопоставляется с артикулом Ozon (`offer_id`).
- Если код не совпал или приёмок нет, позиция остаётся в отчёте с пометкой и без расчёта прибыли.

## Запуск локально

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run streamlit_app.py
```

API-доступы можно ввести в боковой панели. Для локального хранения скопируйте `.streamlit/secrets.example.toml` в `.streamlit/secrets.toml` и заполните значения. Файл с секретами исключён из Git.

## Публикация в Streamlit Community Cloud

1. Создать отдельный GitHub-репозиторий для этой папки и отправить в него файлы проекта.
2. Войти на [Streamlit Community Cloud](https://share.streamlit.io/) через GitHub и выбрать этот репозиторий, ветку и `streamlit_app.py`.
3. В Advanced settings → Secrets задать `MOYSKLAD_TOKEN`, `OZON_CLIENT_ID` и `OZON_API_KEY`.

Секреты не добавлять в GitHub. Если приложение будет доступно по публичной ссылке, любой посетитель сможет видеть его расчёты; не публикуйте персональные или коммерчески чувствительные результаты без подходящей авторизации.

## Модель расчёта

Общие вручную задаваемые параметры применяются ко всем позициям: комиссия, эквайринг, процент выкупа, реклама, налог, доставка, обработка/приёмка, расходы при невыкупе и прочие расходы на единицу.

Прибыль на единицу = выбранная цена − себестоимость − процентные расходы − расходы на доставку и обработку с поправкой на выкуп − расходы при невыкупе − прочие расходы.

Это отдельная компактная модель массового расчёта, а не автоматическое воспроизведение всех меняющихся тарифов и сценариев исходного калькулятора. Перед применением результатов следует сверить ручные параметры с кабинетом Ozon.
